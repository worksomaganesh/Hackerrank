# HackerRank Practice

This repository is my personal collection of **HackerRank coding practice solutions**. I'm using it to build strong programming fundamentals, improve problem-solving, and track my progress as I work toward software development and AI/ML opportunities.

## Goals

- Practise coding consistently and strengthen logical thinking.
- Understand the solution instead of only getting an accepted submission.
- Improve my programming fundamentals and problem-solving skills.
- Keep my solutions version-controlled and accessible through GitHub.
- Review earlier solutions, learn from mistakes, and improve over time.

## What You'll Find Here

Solutions may cover HackerRank domains such as:

- **Problem Solving** — basic algorithms and implementation problems.
- **Python** — language fundamentals and practice challenges.
- **C** — programming fundamentals and problem-solving practice.
- **SQL** — queries and database fundamentals.
- **Other domains and languages** as I explore them.

The repository will grow as I solve more challenges. The exact folder structure and filenames may depend on the HackerRank-to-GitHub sync workflow I'm setting up.

## How I Practise

1. Read the problem carefully and identify the inputs, outputs, and constraints.
2. Try to solve it independently before checking hints or other solutions.
3. Write and test the solution with relevant edge cases.
4. Submit it on HackerRank and review any mistakes.
5. Keep the solution here so I can revisit it and track my progress.
